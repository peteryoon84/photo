# DAC EP 2026 Artist Interview Presentation

2026 대구사진비엔날레 신진작가 특별전의 인터뷰 영상 기획을 설명하는 슬라이드형 웹 프레젠테이션입니다.

## 실행

`index.html`을 브라우저에서 직접 열어도 동작합니다. GitHub Pages에서는 저장소 루트가 그대로 사이트가 됩니다.

- 이전/다음: 좌우 방향키 또는 화면 하단 버튼
- 다음: Space, Enter, Page Down
- 처음/마지막: Home, End
- 모바일: 좌우 스와이프
- 전체 화면: 하단 `⛶` 버튼

## 구성

1. 표지
2. 전시 전체 콘셉트
3. 박가현 — 《무화과 / 요람》
4. 조우성 — 《사진 김장》
5. 조현상 — 《검은 날벌레》
6. 튜나리 — 《LIME STONE GHOST》
7. 납품 구성

## 이미지

대표작 이미지는 대구문화예술회관 제공 보도 이미지에서 작가별로 분리해 프로젝트 내부 `assets/`에 저장했습니다. 외부 이미지 URL을 사용하지 않으므로 오프라인과 GitHub Pages에서 동일하게 표시됩니다.

공개 기사: https://v.daum.net/v/20260714134707942

작가 프로필 사진은 공식 사진을 전달받은 후 각 슬라이드의 `ARTIST PORTRAIT` 영역에 교체해야 합니다. 동명이인 오사용을 피하기 위해 현재는 의도적으로 이니셜 자리표시자를 사용합니다.

## 주의

현재 인터뷰 문구는 실제 발언이 아니라 공개된 전시 정보에 근거한 사전 기획 내용입니다. 촬영 후 실제 인터뷰 발언으로 교체합니다.
